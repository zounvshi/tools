Cloudflare Pages 环境变量配置表（把这 5 行填到 Cloudflare 后台）
================================================================

【1】AUTH_SECRET  （已为你随机生成，直接复制整行）
AUTH_SECRET=dc28cb80eed485973fc532b02a331c02e10e988e11b05c6c5f80b33aa78a0965

【2】ADMIN_CREDENTIALS  （用 gen-admin.html 生成，见《部署步骤.md》第二步，把生成的整行粘贴到这里）
ADMIN_CREDENTIALS=[{"user":"liyt1","hash":"f05e9cb938aa2eb939ffb08b66a4a99a69cd46a4bc21d08d7edcd632781f8d15"}]

【3】R2 存储桶（你已开通 R2，这一组必填）
   TOOLS_BUCKET 不是环境变量，而是在 Cloudflare 后台给 Pages 项目「绑定一个 R2 桶」，
   绑定名【必须】叫 TOOLS_BUCKET（见《部署步骤.md》第二步）。这里只需填下面两个：
R2_PUBLIC_BASE=https://pub-xxxx.r2.dev   （在 R2 桶开启 Public Development URL 后复制到的公开网址，结尾不要带 /）
MAX_UPLOAD_MB=100                        （单次上传上限，单位 MB，默认 100）

【4】USER_PASSCODE  （可选。留空 = 任何人登录后就能提交工具；想加一道门槛就设一个共享口令）
USER_PASSCODE=

【5】MIGRATE_SOURCE_URL  （可选，一般不用填）
   首次上线时，「导入旧数据」会从下面这个旧站点公开地址把历史工具搬进 R2。
   默认就是线上旧地址，无需改动；只有当你把代码部署到【自己】的仓库时才需要改。
MIGRATE_SOURCE_URL=https://raw.githubusercontent.com/zounvshi/tools/main/tools.json

----------------------------------------------------------------
✅ 重要变化：运行时【不再需要任何 GitHub 令牌（GITHUB_TOKEN）】！
   数据（工具列表 / 待审核 / 上传的 exe）全部存在你已开通的 Cloudflare R2 桶里，
   网站运行时不碰 GitHub 写接口。你只需用 GitHub Desktop 把代码推到仓库（走你自己的
   账号登录，不是手动令牌），Cloudflare 连仓库做构建即可。
================================================================
怎么用：
1. 打开 Cloudflare 后台 → 你的 Pages 项目 → Settings → Environment variables
2. 逐个「Add variable」，名字填等号左边，值填等号右边
   （TOOLS_BUCKET 是「绑定」不是变量，去 Functions → R2 bucket bindings 里加）
3. 全部添加后，重新部署一次（Deployments → 最近一次 → Redeploy）
